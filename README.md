# Grupp-projekt
Vi ska arbeta med gruppprojekt där vi ska göra 3 olika spel. Den "lättaste" är sten sax påse där vi ska skriva kod som frågar om namnet och sen spelar. Den "medel" svåra är ett ordgissnings spel där du får en mängd bokstäver som utgör ett ord och sedan gissa fram ordet. Den "svåraste" är mastermind där man ska knäcka en hemlig färgkod.

Vi ska fortsätta med ord gissnings spelet nästa lektion och kanske förbättre sten sax påse programmet lite för det är bara rader av if och elif statements.
